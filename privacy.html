Privacy Policy for D365 Environment Comparison

Publisher: Hai Nguyen

Effective date: August 28, 2026

D365 Environment Comparison is a personal project that helps users compare Microsoft Dynamics 365 Finance & Operations entity metadata and selected OData records between two environments.

Data Access

The extension accesses content from user-selected D365 Finance & Operations websites in order to load entity metadata, compare records, and generate comparison results inside the browser.

Data Collection

This extension does not collect, sell, or transmit personal data to the developer or third parties for advertising, analytics, or marketing purposes.

Local Storage

The extension stores user configuration data locally in the browser, such as saved environment profiles, selected environments, and extension preferences, so users do not need to re-enter them each time.

Specifically, the following is stored locally using the browser's extension storage:

  • Environment profiles you create (a display name and the environment base URL)
  • Which profiles are currently selected as Source and Target
  • Preferences such as the row limit and legal entity filter
  • A cached snapshot of the most recent comparison (entity names, labels, modules and record counts) so results are still visible when the popup is reopened

This data never leaves your browser. It is not transmitted to the developer or to any third party.

Limited Use Disclosure

The use of information received from the extension's permissions adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Specifically:

  • Data accessed from your D365 environments is used only to provide the extension's single user-facing purpose: comparing entity metadata and records between two environments.
  • No data is transferred to the developer or to any third party.
  • No data is used or transferred for advertising, ad targeting, personalisation, or credit-scoring purposes.
  • No human reads your data. All processing happens locally in your browser.

Authentication

The extension uses the user's existing authenticated D365 browser session to request data from the selected environment. Login credentials and passwords are not collected by the developer.

Data Sharing

No user data is sold or shared with third parties, except when required by law.

Purpose Limitation

Any accessed website content is used only to provide the extension's comparison functionality.
